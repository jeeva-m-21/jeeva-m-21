## Engineering approach

```text
Understand the problem
        ↓
Model the domain and constraints
        ↓
Build the smallest useful system
        ↓
Measure, test, and document decisions
        ↓
Iterate toward reliability
```

I care about the boundary between an impressive prototype and dependable software: explicit architecture, reproducible experiments, thoughtful interfaces, and documentation that helps the next engineer move faster.
